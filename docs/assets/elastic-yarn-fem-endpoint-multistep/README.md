# A short complete-FEM and yarn endpoint-contact trajectory

This bounded CPU experiment advances the represented **2,057-node, 10,240-tetrahedron** elastic body and a locally authored two-node yarn for **64 accepted 20 µs steps (1.28 ms)**. Every accepted step evaluates all tetrahedral stresses, determinants and gathered forces, and checks all 1,280 boundary faces against the yarn. The selected face is `[5,1814,1347]`; its two endpoint projection rows use a shared reciprocal 2×2 nonnegative normal impulse block across the actual five owners.

The earlier frozen block stopped at attempted step 13 after 12 accepted steps. Its fixed centroid witness was **2.206 µm farther** than the actual selected-face closest point, which had moved to yarn endpoint `u=1`. The extension uses the reconstructed closest segment–triangle witness and keeps both endpoint rows. This **replaces** the fixed centroid-to-oracle consistency admission with closest-witness-to-oracle consistency; because the reconstruction uses the oracle's `u` and barycentric coordinates, it is not an independent centroid check. The 2 µm geometry budget, J/rest/material checks, endpoint interior rows, all-face velocity scan, reciprocal momentum/angular response, actual contact kinetic passivity and whole-state rollback remain enforced.

All first 12 accepted physical owner states are byte-identical between the frozen and extended models: the complete 2,059-owner position/velocity buffer, all 10,240 stress/J/U records and 2,059 gathered force records match at each step. The complete state hashes differ because the new accepted geometry witness is stored in the ledger and cache. The old model still rejects step 13; the endpoint model accepts that same exact-timestep checkpoint, with an interior selected-face contact and final minimum `det(F)=0.4180681225`. Independent invalid-J and invalid-area controls roll back the complete state.

The extended model accepts 32 steps through **640 µs**, reconstructs its exact complete checkpoint, then accepts **32 more steps with the same binary timestep** through 1.28 ms. Both segments have exact replays. The run stops at this chosen cap; no later feature or support behavior is claimed. Across all 64 accepted steps, the smallest `det(F)` is **0.3822734716**, and the final global yarn gap is **−1.591522463 µm** with normal speed **+8.15e−17 m/s**. Both endpoint projected barycentric weights stay strictly interior; the minimum across 64 steps is **0.141392457**. The two geometry-history audits retain every accepted closest feature and endpoint row.

Over the separate **320 µs** matched interval, 16×20 µs and 32×10 µs both pass admission. Their maximum owner position difference is **1.12632524e−7 m**, maximum velocity difference **3.74175104e−4 m/s**, and final total-energy difference **6.85579146e−8 J**. The physical energy residuals are **+3.17171224e−8 J** and **+2.65771022e−8 J**, respectively. Across the linked 64-step run, the residual sums to **+3.22080886e−7 J** and remains open. One matched interval is a discretization observation, not temporal convergence.
