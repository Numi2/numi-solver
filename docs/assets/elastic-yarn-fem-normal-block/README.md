# Complete elastic body with a shared yarn normal block

This CPU experiment advances the complete captured **2,057-node, 10,240-tetrahedron** elastic body and a locally authored two-node yarn for **1 µs**. The frozen single-centroid response left its true closest endpoint approaching at **0.0679014159 m/s**. A shared, reciprocal two-row normal block brings the final closest-feature normal velocity to **+4.77e−18 m/s** while the final gap remains **−0.999801 µm**, inside the unchanged 2 µm geometry target. This is a bounded local contact result, not a full yarn, fruit or bag scene.

Run from this repository with Python 3:

```sh
python3 docs/assets/elastic-yarn-fem-normal-block/reproduce.py
```

The runner verifies the nine lossless payloads and seven frozen physical source files in the [public full FEM pack](../elastic-yarn-fem-body/payload-manifest.json), plus the [published contact fixture](../elastic-yarn-fem-frame38-provenance.json). It creates a fresh private directory under `build/`, reconstructs only **new receipts for actually supplied physical files**, executes the unchanged centroid and normal-block source in sequence, and checks each run's nine complete state, stress, force and ledger outputs byte for byte against the reviewed owner result. Neither source is changed to make the public run pass. The runner also checks path-independent physical metric digests, exact replay, half steps, four rollback rejections and the final global feature response. It needs no GPU, Metal compiler or optional Python package.

The published run finished with **actual exit 0**: both unchanged sources exited 0, all **18 output files** were byte-identical, and both metric digests matched. Its [terminal log](published-run.log), [exit marker](published-run.exit), [fresh launch binding](published-launch.json) and [result](published-reproduction-result.json) retain that execution. The [manifest](reproduction-manifest.json) records exact source, baseline, full-body payload, fixture, independent-review and expected output hashes. The [independent review](independent-review.md) also exited 0 on the frozen normal-block source and complete owner outputs; its [detailed result](independent-review-result.json) is retained separately from this portable replay.

The two contact rows use both actual FP64 yarn endpoint positions projected strictly inside the same selected boundary triangle `[5,1814,1347]`. Their **shared 2×2 nonnegative impulse solve** applies one summed reciprocal velocity change to the two yarn and three continuum owners. All 10,240 tetrahedral stresses and all 2,057 individual body forces are evaluated before and after the newly chosen FP64 support-Verlet split. Initially and finally, all 1,280 boundary faces are checked; the selected face remains the minimum. Exact replay, one 1 µs versus two 0.5 µs steps, all four block active-set controls and required whole-state rollback negatives pass. An additional late-failure control retains a previously accepted clock, warm state, cache and ledger after a second private step fails the final global velocity gate; its [receipt](late-rollback-result.json) is distinct from the physical positive run.

Contact kinetic dissipation is **3.128025833486678e−5 J**. The measured physical energy balance residual is **+5.31534415568857e−9 J** and remains open; bookkeeping identity is not energy closure. Final minimum `det(F)` is **0.4243286839455109**. The one-step versus two-half-step maximum position difference is **1.012e−11 m**; that single comparison does not establish temporal convergence.

The [normal-block evidence](normal-block-owner-evidence.json) and [source receipt](normal-block-owner-receipt.json) bind the original owner run; the [centroid evidence](centroid-owner-evidence.json) and [receipt](centroid-owner-receipt.json) preserve the diagnostic failure. Their original absolute paths are historical run metadata. The portable runner checks the available public bytes and writes new path-specific input receipts without asserting an unavailable native checkpoint or original authoring executable. The exact represented inverse-rest rows were reconstructed from the frozen owning source; the historical uploaded buffer and full native frame-38 checkpoint were not captured.

The active-set face queries and velocities are numerical FP64 observations, not outward-rounded distance certificates or moving CCD. Edge and feature switches, other simultaneously active faces, internal yarn elasticity, friction, full-bag/fruit coupling, generic yarn-floor resting, long trajectory and spatial/temporal convergence remain open. The initial authored overlap is within the existing 2 µm contact accuracy. No production solver or native GPU scene was changed by this research bundle.
