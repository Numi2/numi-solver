# Portable CPU area-admission study

Run from any checkout, using Python 3.11 or newer and only the standard library:

```sh
python3 docs/assets/elastic-yarn-area-admission/reproduce.py
```

The command verifies `source-manifest.json`, copies this package into a fresh
temporary directory, reruns the corrected qualifier, six explicit unresolved
or rejected controls, the frozen strict-gate counterexample, and the
independent review. It retains every actual exit, log, result, and
`reproduction.json` in the printed output directory. `--output-dir` can name a
new directory if you want to retain it at a predictable path. It does not
launch a native binary or GPU job.

`area_admission.py` is the separately reviewed correction to the frozen source
under `historical/area_admission.py`. Only the velocity helper's two strict
gate checks changed from `<` to `<=`. The complete original qualifier result
is preserved in `historical/result.json`; the corrected candidate's
original full run produced the same bytes. The public qualifier uses the
selected three-owner chord, sealed first-study math source, and first-study
result included in `legacy/`. Its 215 temporal case rows, 128 represented
velocity case rows, and domain controls reproduce exactly. The only changed
result fields are the external-input binding counts: the historical run
checked 17 source/execution files in the private workspace, while this package
checks four included legacy inputs. The unavailable historical native binary
and complete owner histories remain SHA commitments, not revalidated bytes.

The `legacy/chord-owners.json` values come from owner indices 1433, 1444,
and 1445 in retained frame-0 and frame-620 OBJ files. It is a declared
rest-to-failure linear chord used to exercise the algorithm. Saved velocities
and intermediate owner histories for that chord do not exist. Its passing
preventive response does not repair or replay the actual CPU96 cloth drop.

The primitive certifies strict area for represented affine three-owner paths
using exact-rational degree-at-most-four root isolation, and admits a local
rounded velocity response only when actual represented kinetic change is
nonpositive and momentum residuals meet stated bounds. A 128-node temporal
budget and 16 boundary retries fail closed. It does not own simultaneous
incident-face events, the native integrator's rounded path, or all affected
yarn, bend, contact, and external-work terms. No production integration or
full-scene qualification is claimed.
